🎤 Tthe Grind (TTG) – Tour Announcement Landing Page
Nowoczesny landing page ogłaszający trasę koncertową Tthe Grind (TTG). Projekt INSPIROWANY jest estetyką stron koncertowych polskich raperów (m.in. Sobla) – całe ujawnianie miast i szczegółów trasy odbywa się w formie interaktywnej konwersacji na czacie.

Podgląd:  https://kub87aa.github.io/TTG/

✨ Główny Koncept i Funkcje
💬 Czat iMessage (iOS Dark Mode): Prezentacja miast trasy w formie konwersacji między artystami (szare bąbelki odebrane, niebieskie i zielone bąbelki wysłane).

🌌 Neonowe, Mieniące się Tło: Głęboki Dark Mode z efektownymi rozbłyskami światła dopasowany do koncertowego klimatu.

📜 Animacje GSAP + ScrollTrigger: Płynne wsuwanie i powiększanie się kolejnych bąbelków czatu podczas przewijania strony.

📱 Responsive Web Design: Pełna adaptacja layoutu do ekranów smartfonów, tabletów i komputerów stacjonarnych.

🛠️ Stos Technologiczny
HTML5 & CSS3: Semantyczna struktura strony oraz dedykowany styl iMessage (z wykorzystaniem !important do prostego nadpisywania klas narzędziowych).

JavaScript (Vanilla JS): Logika powiązana z animacjami.

GSAP 3 + ScrollTrigger: Biblioteka do profesjonalnych animacji napędzanych skrolowaniem strony.

Tailwind CSS & Flowbite: Komponenty UI oraz baza nawigacji i stopki.

Google Fonts: Typografia (Roboto, Seymour One).
